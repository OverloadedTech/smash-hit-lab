# Code of Conduct

This is a research project focused on reverse engineering and documentation.
All interactions should be respectful, evidence-based, and focused on the
technical subject matter.

We commit to:
- Being precise and honest about what is confirmed versus hypothesized
- Citing sources, measurements, and artifacts for every claim
- Preserving failed experiments and not relabeling them as successful
- Maintaining the project as clearly unofficial and not implying any
  publisher endorsement

Harassment, personal attacks and publishing someone's private information are
not acceptable. Maintainers may hide comments, close threads and block accounts
when a thread stops being about the research.

Report a problem to [Luca Zani (OverloadedTech)](https://github.com/OverloadedTech)
using the contact information on that profile. Security issues go through
[SECURITY.md](SECURITY.md) instead.
